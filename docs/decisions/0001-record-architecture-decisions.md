# 1. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-02

## Context

This project involves many technical choices (processing engine, storage format,
validation strategy, models). Without a record, the reasoning behind them gets lost
and is hard to revisit or explain later.

## Decision

Each significant decision is written as a short Architecture Decision Record (ADR)
in this folder, numbered in order, with: context, decision, alternatives considered
and consequences.

## Consequences

- Decisions can be reviewed and challenged with their original reasoning.
- A decision that changes gets a new ADR that supersedes the old one; old ADRs are kept.
